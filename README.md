## 项目简介

教务系统中，**总评成绩通常由多条权重链计算得出**（如 `总评 = ROUND(平时分 × 0.8 + 出勤 × 0.2)`）。当课程组需要把总评对齐到既定标准（统一及格线、成绩分布要求、重修归档口径）时，人工做法是：

> 在 Excel 里一个格子一个格子试数字 → 看总评列是否跳到位 → 不行再改 → 一表 60 行要花 15~20 分钟

这个过程的本质是**求一个整数解**，完全可以用数学反解替代。本工具做的事情：

1. 读取每行的目标总评、出勤分；
2. 按权重链反解出**所有**能让结果恰好命中目标的平时分；
3. 在合法集合内挑一个，写入平时分列；
4. 保存为新文件并自动备份原表，同时输出校验报告。

## 算法原理

设平时分为 `x`（整数），出勤分为 `a`，权重为 `w_i`、`w_j`，目标总评为 `T`。

```
总评 = ROUND(w_i · x + w_j · a)
```

要让总评恰好等于 `T`，只需让加权值落在**四舍五入的收敛区间**内：

```
T - 0.5  ≤  w_i · x + w_j · a  <  T + 0.5
```

对 `x` 求解：

```
(T - 0.5 - w_j · a) / w_i  ≤  x  <  (T + 0.5 - w_j · a) / w_i
```

取该半开区间与 `[HW_MIN, HW_MAX]` 的交集内的**全部整数**，即为可行解集。工具从中按"使用次数最少优先 + 抑制连续重复"选值，保证结果既精准、又不会出现整列同一个数的异常形态。

### 两个容易被忽略的实现细节

**1. Python 的 `round()` 不是 Excel 的 `ROUND()`**

Python 使用**银行家舍入（round-half-to-even）**：`round(90.5) == 90`；
Excel 使用**半进位（round-half-away-from-zero）**：`ROUND(90.5,0) == 91`。

如果直接用 `round()` 反解，所有落在 `.5` 边界上的行都会系统性错位一格。本项目的 `excel_round()` 显式复刻了 Excel 语义，测试用例 `test_half_up_matches_excel` 专门锁死这条行为。

**2. 必须双开工作簿**

`openpyxl` 在 `data_only=True` 模式下读的是**公式缓存值**，但保存时会丢掉公式；在默认模式下能保留公式，却读不到公式的计算结果。因此本工具同时打开两份：一份只读缓存值，一份负责写入并保存。这样"读到目标值"与"保留原公式"才能同时成立。

### 三重校验

| 校验 | 实现 |
| :--- | :--- |
| 数值范围 | 候选集天然取自 `range(HW_MIN, HW_MAX + 1)`，写入后再次断言 |
| 波动离散度 | 选值优先取使用次数最少的候选（轮转分配），避免结果塌缩到单一数值 |
| 防连续重复 | 记录最近 `MAX_CONSECUTIVE` 次取值，若再选同值会超限则剔除；候选集不足时放宽并计数上报 |

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 准备数据表

表头下方每行一名学生，至少需要三列：**出勤分（或固定值）、平时分（待赋值，留空）、目标总评**。
仓库自带示例表 `examples/demo_scores.xlsx`（60 行虚构数据），可直接体验：

```bash
python examples/make_demo.py     # 如需重新生成示例表
```

### 3. 修改配置

打开 `score_assigner.py`，只改顶部配置区：

```python
FILE_PATH = r"examples/demo_scores.xlsx"   # 目标 Excel 文件路径
SHEET_NAME = "Sheet1"                      # 工作表名称
DATA_START_ROW = 2                         # 数据起始行号

HW_MIN = 60                                # 平时分最小值
HW_MAX = 99                                # 平时分最大值
WEIGHT_I = 0.8                             # 平时成绩权重
WEIGHT_J = 0.2                             # 出勤成绩权重
TARGET_COL = "L"                           # 目标总评列
J_VALUE = 100                              # 出勤列固定值（单元格为空时使用）
```

### 4. 运行

```bash
python score_assigner.py                  # 正式运行：写入 + 备份
python score_assigner.py --dry-run        # 只试算，不落盘
python score_assigner.py --file 2026秋_统计学.xlsx --sheet Sheet1
```

运行完成后生成 `原文件名_filled.xlsx`，**默认不覆盖原文件**，并在同目录自动生成带时间戳的备份。

## 配置项说明

| 配置项 | 含义 | 示例 |
| :--- | :--- | :--- |
| `FILE_PATH` | 目标 Excel 路径 | `examples/demo_scores.xlsx` |
| `SHEET_NAME` | 工作表名（区分大小写） | `Sheet1` |
| `DATA_START_ROW` | 数据起始行（跳过表头） | `2` |
| `ID_COL` / `NAME_COL` | 学号、姓名列，仅用于报告定位 | `B` / `C` |
| `ATTEND_COL` | 出勤成绩列（只读） | `H` |
| `HW_COL` | 平时分列（**写入列**） | `J` |
| `TARGET_COL` | 目标总评列（只读） | `L` |
| `HW_MIN` / `HW_MAX` | 平时分合法区间（闭区间） | `60` / `99` |
| `WEIGHT_I` / `WEIGHT_J` | 平时分、出勤分权重 | `0.8` / `0.2` |
| `J_VALUE` | 出勤列空白时的兜底固定值 | `100` |
| `MAX_CONSECUTIVE` | 同一数值最多连续出现次数 | `2` |
| `SEED` | 随机种子（同配置结果可复现） | `20260101` |
| `OUTPUT_SUFFIX` | 输出文件后缀 | `_filled` |

多学科配置示例见 `examples/config_examples.py`，内含权重链、区间、列映射三套预设。

## 适用场景

- 高校教务平时成绩、作业成绩的批量赋值与对齐
- 多学科差异化分值规则、权重比例下的成绩折算
- 目标总评倒推平时分、成绩口径标准化
- 批量生成符合区间与离散要求的模拟成绩数据（用于系统联调、报表测试）

> **使用边界**：本工具只负责"给定目标值 → 反解合法取值"这一步数学计算。目标成绩应由任课教师或教务管理部门依据教学管理规定确定；工具不替代这一判断，也不适用于未经授权的成绩修改。

## 已知局限

- `openpyxl` 会保留公式、单元格样式与行列结构，但**不保留**图片、图表、数据透视表等对象。建议在副本上运行（脚本已自动备份）。
- 输出文件设置了 `fullCalcOnLoad`，首次用 Excel / WPS 打开时会触发全量重算，总评列随即刷新为正确值。
- 目标总评需落在可达区间 `[w_i·HW_MIN + w_j·a, w_i·HW_MAX + w_j·a]` 内，例如默认配置（出勤 100）的可达区间为 `[68, 99]`；区间外的行会被报告为"目标不可达"。
- 仅支持 `.xlsx`；`.xls` 需先另存为 `.xlsx`。
